# Python-Based Temperature Monitoring and Alarm System

## 1. Project Overview
The Temperature Monitoring and Alarm Checker is a simple Python application developed to monitor temperature readings and identify unusually high temperatures.

The program collects five temperature values from the user and analyses them to determine the machine's temperature condition.

## 2. Main Features
- Accepts five temperature readings.
- Stores readings in a Python list.
- Calculates the maximum and minimum temperatures.
- Calculates the average temperature.
- Displays an alarm when the temperature exceeds the set limit.
- Identifies the exact readings that exceed the limit.
- Checks invalid inputs and requests a valid number.

## 3. How to Run the Program
1. Install Python or use a Python IDE such as Pyto.
2. Open `temperature_monitor.py`.
3. Run the program.
4. Enter five temperature values when requested.
5. View the temperature analysis and machine status.

## 4. Sample Results

Sample temperature readings:
35, 42, 48, 65, 82.

Program results:

- Minimum temperature: 35°C
- Average temperature: 54.4°C
- Machine condition: CRITICAL
- High-temperature alerts: Readings 4 and 5.
